# Mini Fluxxion CRM
 <br>
<===================== Features =======================>  <br>

🔹 Clients <br>
    - View all clients in a table or list view <br>
    - Search, filter, and tag clients <br>
    - View detailed client profile on click <br>
🔹 Leads <br>
    - Track leads across various stages (e.g., New, Contacted, Proposal, Won) <br>
    - Implement a Kanban board UI to drag and drop leads between stages <br>
🔹 Tasks & Notes <br>
    - Add reminders or tasks per client or lead <br>
    - View tasks in a simple calendar view or list <br>
    - Add sticky notes or comments per client or lead <br>
