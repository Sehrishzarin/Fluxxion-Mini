# Mini Fluxxion CRM

<===================== Features =======================>

🔹 Clients
    - View all clients in a table or list view
    - Search, filter, and tag clients
    - View detailed client profile on click
🔹 Leads
    - Track leads across various stages (e.g., New, Contacted, Proposal, Won)
    - Implement a Kanban board UI to drag and drop leads between stages
🔹 Tasks & Notes
    - Add reminders or tasks per client or lead
    - View tasks in a simple calendar view or list
    - Add sticky notes or comments per client or lead
